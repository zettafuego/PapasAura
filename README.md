# PAPAS AURA

Tres variedades de papa saltan por sus vidas. Ganan si farmean **300 aura**.

Proyecto de Unity 6 (`6000.5.0f1`), el mismo editor que AYNI.

## Las 3 papas

| Papa | Variedad | Controles | Extra |
|---|---|---|---|
| **Russet** | papa blanca / russet | `A` `D`  salto `W` | salto más alto |
| **Amarilla** | papa amarilla | flechas  salto `↑` | más aura de orbes + imán |
| **Morada** | papa morada | `J` `L`  salto `I` | más aura en el aire |

Si nadie toca a una papa durante un rato, **salta sola**. Puedes jugar las tres, o una sola y las otras se defienden.

## Cómo se gana / se pierde

- Recogen orbes dorados de aura
- El tiempo en el aire suma aura (sobre todo Morada)
- Saltar sobre la cabeza de otra papa da aura
- Un salto clutch cerca de la sartén da mucho aura
- **300 aura de equipo** = ganan y viven
- Si las tres caen a la sartén que sube = **fritas**

`ENTER` para empezar. `R` para reiniciar.

## Cómo abrirlo

1. Doble clic en `abrir_en_unity.bat`
2. En Unity Hub: **Add** → carpeta `PapasAura`
3. Abre el proyecto con Unity **6000.5.0f1** (o 6000.x)
4. Abre `Assets/Scenes/PapasAura.unity`
5. Pulsa **Play**

El juego se arma solo al darle Play: no hace falta colocar prefabs a mano.
